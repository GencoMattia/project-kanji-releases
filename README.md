# Kakō 書こう — release

Qui ci sono gli APK Android di Kakō, un'app per studiare i kanji scrivendoli.
Il codice sta in una repo privata. Le release vengono pubblicate in automatico
da GitHub Actions: non modificarle a mano.

## Installare
1. Apri l'ultima release in [Releases](../../releases/latest) e scarica
   `kako-X.Y.Z.apk` sul telefono Android. Serve un telefono a 64 bit (arm64).
2. Aprilo e consenti l'installazione da questa sorgente quando Android lo chiede.

Dopo la prima installazione, l'app controlla da sola se ci sono versioni nuove
e le propone all'apertura. Le novità di ogni versione sono in [CHANGELOG.md](CHANGELOG.md) e nelle note di ogni release.
